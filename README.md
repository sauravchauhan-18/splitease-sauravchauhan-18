# SplitEasy

A frontend-only shared expense splitter. Open `index.html` in a browser or deploy this folder as a static site (for example, with Vercel or Netlify).

## Week 1 features

- Add and remove people in a group.
- Record an expense, its amount, and who paid.
- Split all expenses equally among the current group.
- See group spend, each person's share, who is owed, and suggested repayments.
- Rename a group and copy a plain text summary.
- Keep the current group on this device with local storage.

No backend or build step is required. Data stays in the browser where the page is opened.
